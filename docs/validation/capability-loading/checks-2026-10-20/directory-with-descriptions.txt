- mcp.everything (16 tools): Audience: These instructions are written for an LLM or autonomous agent integrating with the Everything MCP Server.
  mcp__everything__echo: Echoes back the input string
  mcp__everything__get-annotated-message: Demonstrates how annotations can be used to provide metadata about content.
  mcp__everything__get-env: Returns all environment variables, helpful for debugging MCP server configuration
  mcp__everything__get-header-params: Returns its region argument and the Mcp-Param-Region HTTP header it arrived in.
  mcp__everything__get-resource-links: Returns up to ten resource links that reference different types of resources
  mcp__everything__get-resource-reference: Returns a resource reference that can be used by MCP clients
  mcp__everything__get-structured-content: Returns structured content along with an output schema for client data validation
  mcp__everything__get-sum: Returns the sum of two numbers
  mcp__everything__get-tiny-image: Returns a tiny MCP logo image.
  mcp__everything__gzip-file-as-resource: Compresses a single file using gzip compression.
  mcp__everything__trigger-list-changed: Sends a notifications/<list>/list_changed for the tool, prompt or resource list.
  mcp__everything__trigger-log-messages: Sends one log message at each logging level during the call.
  mcp__everything__trigger-long-running-operation: Demonstrates a long running operation with progress updates.
  mcp__everything__trigger-resource-update: Sends a notifications/resources/updated for a resource URI.
  mcp__everything__toggle-simulated-logging: Toggles simulated, random-leveled logging on or off.
  mcp__everything__toggle-subscriber-updates: Toggles simulated resource subscription updates on or off.
- mcp.fetch (1 tool):
  mcp__fetch__fetch: Fetches a URL from the internet and optionally extracts its contents as markdown.
